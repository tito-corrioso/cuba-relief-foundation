# Cuba Relief Foundation

Sitio web para la fundación de ayuda humanitaria a familias en Cuba.

## 🚀 Despliegue Rápido

### GitHub Pages (GRATIS)
1. Crea repositorio `cuba-relief-foundation`
2. Sube todos los archivos
3. Activa GitHub Pages en Settings > Pages > Deploy from branch `main`

### Netlify (GRATIS)
1. Arrastra la carpeta a [netlify.com/drop](https://netlify.com/drop)
2. ¡Listo en segundos!

### Vercel (GRATIS)
1. Conecta tu GitHub
2. Importa el repositorio
3. Deploy automático
